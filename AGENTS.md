# TUI Version

We shall create a terminal UI version of the game you find in snake.html, .js, and .css.

It shall use ANSI codes, no curses.

It shall support both cursor kays and wasd.

It shall have a start screen like in index.html and also provide the same field sizes.

It shall look similar.

It uses the 256 color mode.

It uses half and full height block characters, depending on the scaling.

You shall place it inside a directory named tui_snake.
