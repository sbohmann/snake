# TUI Snake

ANSI terminal version of the browser Snake game.

Run from the repository root:

```sh
python3 tui_snake/tui_snake.py
```

Pass a field size to skip the start screen:

```sh
python3 tui_snake/tui_snake.py 40
python3 tui_snake/tui_snake.py 20
python3 tui_snake/tui_snake.py 10
```

Controls:

- Arrow keys or `wasd` move the snake.
- `hjkl` and the browser game's `asdf` bindings also work.
- Space pauses movement.
- Escape restarts the game.
- `q` exits.
